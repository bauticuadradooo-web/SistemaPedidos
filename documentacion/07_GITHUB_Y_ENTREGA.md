# Repositorio GitHub y entrega

Repositorio configurado en el proyecto original: https://github.com/bauticuadradooo-web/SistemaPedidos
Visibilidad pública verificada mediante la API de GitHub el 21/10/2026. Esta entrega reúne el código y la documentación en la rama main. El historial de commits permite identificar la revisión utilizada para la evaluación.

## Contenido del paquete académico
README.md como entrada; documentacion/ para descripción, alcance, requisitos, arquitectura, manual, bitácora y verificación; herramientas/ para inventario y dependencias; app/, tests/ y scripts/ para código; requirements.txt, .env.example y .gitignore para instalación. No se incluye guion de presentación.

## Incorporación al repositorio
Desde una copia de trabajo autorizada del repositorio, agregar las carpetas y archivos preparados, revisar git diff y git status y ejecutar pruebas. Confirmar que no se agregan .env, bases reales, comprobantes, registros ni entornos virtuales. Crear un commit descriptivo y publicarlo en la rama acordada. Esta copia del proyecto es material de referencia sincronizado y no debe editarse para sustituir el repositorio original.

- Abrir LEER_PRIMERO.html y comprobar navegación y documentación.
